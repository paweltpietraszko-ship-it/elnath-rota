FINDING B-R4-2 — TEST NN NIE DOWODZI, ŻE NN SAMO KWALIFIKUJE MIESIĄC

Test planuje pełny miesiąc i wywołuje `mark_not_worked` dla jednego
Assignmentu. Niezależna diagnostyka bieżącego snapshotu po tej operacji

- 29 Assignmentów `PLANNED` bez operational_code;
- 1 Assignment `CANCELLED/NN`.

Warunek zamknięcia: przez publiczne API aplikacji doprowadzić bieżący snapshot
do stanu, w którym wszystkie pozostałe Assignmenty również są NN albo jedynym
Assignmentem kwalifikującym miesiąc jest CANCELLED/NN; jawnie potwierdzić brak
innego stanu Assignment i dopiero wtedy asertować obecność miesiąca. Nie
zmieniać SQL ani dodawać test-only operacji usuwania.
