A4 — CALENDAR UI COLLAPSES TWO BACKEND STATES THAT READINESS DISTINGUISHES
STATUS: FAIL
CONTRACT:
- brief.md:169-182 requires list_calendar_days + per-day set_calendar_day and
  describes a year/month holiday-toggle list
EVIDENCE AT DECLARED BASE 7349ae6:
- calendar_repository.py:36 returns only persisted CalendarDay rows
- bootstrap.py:321-344 treats every absent date row as missing configuration
- CalendarDay(date, holiday=False) is therefore not equivalent to no row
IMPACT:
- an unchecked toggle can mean either a saved non-holiday or an unconfigured
  date; the UI cannot truthfully display readiness or know which false rows
  must be persisted
CLOSURE:
- specify how absent dates are represented in the chosen month/year range
- specify the save rule that produces explicit CalendarDay rows for ordinary
  days as well as holidays, or cite an existing owner that already defines it
- do not treat an absent row as holiday=False silently
