BOUND OF THE VERDICT

An absolute HARD necessarily means that an input whose only mathematical
solutions require a third consecutive shift must return no automatic plan.
That is the frozen OWNER behavior, not a solver defect. This recheck does not
prove such inputs can never occur; it shows that they did not occur in the
saved September objects, the 24-month sweep or the 30 witnessed feasible
stress cases. A defect would require a reproduced input where a no-triples
solution exists but f44f7c3 fails to find it; none was found.

No product code, frontend or PDF code was changed. Visual PDF evaluation is
not a relevant gate for this operational solver-only recheck.
