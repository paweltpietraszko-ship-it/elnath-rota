- T23b-30 requires solver/validator agreement for both protections.

Observed sibling failures:

1. constraints._add_one_employee_weekly_rest creates anchors from every
   prospective slot and considers only gaps between adjacent anchors. An
   unselected slot occupies no time, but its endpoints still split a genuinely
   longer free interval. Seven daily candidate slots forced unselected leave
   168h free according to the oracle, yet the CP-SAT model is INFEASIBLE.

prospective-but-unselected boundaries must not occupy time, and fixed-only work
must not disappear. The production test file contains validator/oracle tests but
no solver test exercising T23b-30, which is why both classes passed unnoticed.
