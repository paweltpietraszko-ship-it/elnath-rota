REPRO A — an unrelated mutation inside #root hides a dead control

1. Click the inert diagnostic control.
2. Within 100 ms change an unrelated attribute on #root, representing another
   component/background refresh within the React application.
3. Wait beyond the 800 ms stalled window.

Observed: no ACTION_STALLED is recorded. The root-wide MutationObserver credits
every mutation in the entire React application to the latest click. Moving the
observer from body to #root removed only the original body-attribute example;
it did not create causal attribution.

REPRO B — a delayed error resolves a newer, unrelated click

1. Click action A, which throws an asynchronous error after 300 ms.
2. After 50 ms click inert action B.
3. Wait beyond both stalled windows.

Expected:
- A is resolved by its error and is not stalled;
- B has no effect and is stalled.

Observed:
- A is incorrectly ACTION_STALLED;
- B is incorrectly treated as resolved.

resolveMostRecentAction() associates the error with whichever click happened
most recently, not the click that caused the error.

REQUIRED CORRECTION

Close the causal invariant rather than adding another DOM scope or timing
special case:

- an unrelated mutation elsewhere in the React root must not resolve a click;
- a delayed error must not resolve a newer action that did not cause it;
- when causality is genuinely unavailable/ambiguous, fail conservatively rather
  than declaring an unrelated action successful;
- retain the single-click R1 cases and both concurrent/unrelated R2 cases as the
  regression family.

This report does not prescribe a new architecture. The implementation may use
the existing shared seams, explicit action completion, or another minimal
mechanism, provided the same action identity survives all supported result
paths.
